# The Zafran Tales 🍽️

A modern full-stack restaurant website built using React, Vite, Node.js, and Express.  
This project showcases a responsive restaurant platform with multiple pages including menu, reservations, events, and customer reviews.

## 🚀 Features

- Responsive modern UI
- Restaurant landing page
- Menu section
- Reservation page
- Customer reviews
- Backend API integration
- Clean component-based architecture

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS3

### Backend
- Node.js
- Express.js

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/sutapamandal22/the-zafran-tales.git
```

### 2️⃣ Navigate into the Project

```bash
cd the-zafran-tales
```

## ▶️ Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend will run on:

```bash
http://localhost:5173
```

## ▶️ Run Backend

Open another terminal:

```bash
cd backend
npm install
node server.js
```

Backend will run on:

```bash
http://localhost:5000
```
